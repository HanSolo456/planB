# planB — Operations Web Client

> React 19 + TypeScript + Vite frontend for the planB travel disruption recovery platform.

## Features Included
- **Flight Manifest UI**: Tabular, high-density flight operations dashboard.
- **Topological Visualizer**: Interactive multi-leg itinerary timeline and connection health indicators.
- **Disruption Simulation Lab**: Instant triggers for delays, train cancellations, and hotel disruptions.
- **Recovery Drawer**: Real-time scored alternative re-accommodations with transparent AI reasoning.
- **Raw PNR Importer**: Live parser for unstructured booking confirmations.

## Local Development

```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Build production bundle
npm run build
```

See root [`../README.md`](../README.md) for full system architecture, data models, and scoring algorithms.
